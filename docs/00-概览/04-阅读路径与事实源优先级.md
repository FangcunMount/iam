# 阅读路径与事实源优先级

## 事实源优先级

1. 源码与运行时行为。
2. OpenAPI、proto、配置、迁移。
3. 测试。
4. 现行 `docs/`。
5. `_archive/`。

旧文档只能作为素材。任何旧结论进入现行正文前，都要重新核对代码或契约。
