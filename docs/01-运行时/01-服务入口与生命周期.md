# 服务入口与生命周期

> 状态：待补证据 · 骨架初稿，待与代码/契约核对。

## 30 秒结论

iam-apiserver 的启动主线是：

```text
cmd/apiserver
  -> internal/apiserver/app.go
  -> internal/apiserver/process
  -> internal/apiserver/container
  -> REST/gRPC server
```

## 职责边界

| 层 | 职责 |
| --- | --- |
| `cmd/apiserver` | 命令入口 |
| `internal/apiserver/app.go` | 构造应用命令 |
| `internal/apiserver/process` | 配置、资源、生命周期、优雅关闭 |
| `internal/apiserver/container` | 模块装配 |
| `transport/rest` / `transport/grpc` | 协议服务注册 |
