# 组合根与依赖装配

## 30 秒结论

`internal/apiserver/container` 是 IAM 的组合根。它把配置、数据库、Redis、JWT、Casbin、微信 API、Suggest runtime 等基础设施装配到各业务模块。

## 模块装配

| 模块 | 组合根 |
| --- | --- |
| Identity | `../../internal/apiserver/container/identity` |
| AuthN | `../../internal/apiserver/container/authn` |
| AuthZ | `../../internal/apiserver/container/authz` |
| IDP | `../../internal/apiserver/container/idp` |
| Suggest | `../../internal/apiserver/container/suggest` |

## 原则

- transport 不直接构造 repository。
- application 不依赖具体 infra。
- domain 只依赖端口。
- container 是跨层依赖汇合点。
