# 后台任务与优雅关闭

## 30 秒结论

后台任务包括授权事件传播、Suggest 索引刷新、缓存或定时任务等。它们必须被生命周期管理托管，不能绕过 process/container 自行启动。

## 典型后台任务

| 任务 | 说明 |
| --- | --- |
| AuthZ Outbox Relay | 发布授权版本变化事件 |
| AuthZ Runtime Reload | 授权事实变化后的运行时刷新 |
| Suggest Refresh | Full / Delta / Snapshot 索引刷新 |
| Scheduler | 统一调度和停止后台任务 |

## 关闭原则

- 收到关闭信号后停止接收新请求。
- 后台任务按生命周期顺序停止。
- 外部资源由 process 统一关闭。
