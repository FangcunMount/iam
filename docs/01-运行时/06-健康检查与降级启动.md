# 健康检查与降级启动

> 状态：待补证据 · 骨架初稿，待与代码/契约核对。

## 30 秒结论

IAM 主服务应优先保证核心身份、认证、授权能力可观测。辅助能力可以按配置降级，但降级必须明确暴露在健康检查或运行状态中。

## 关注点

| 能力 | 降级语义 |
| --- | --- |
| Identity | 核心能力，通常不可缺失 |
| AuthN | 核心能力，通常不可缺失 |
| AuthZ | 核心能力，运行时 reload 失败需可观测 |
| IDP | 外部依赖失败时影响对应第三方身份源能力 |
| Suggest | `Required=false` 时可降级为空结果，不阻断主服务启动 |
