# Identity 模块总览

## 模块定位

Identity 负责身份事实，不负责认证登录态、权限判定或联想搜索索引。

| 负责 | 不负责 |
| --- | --- |
| User | Credential、Challenge |
| Profile | Principal、Session、Token |
| ProfileLink | Subject、Permission、RoleBinding |
| 身份事实查询 | Suggest 索引刷新和查询 |

## 核心模型

```text
User
  -> ProfileLink
  -> Profile
```

Identity 是 AuthN、AuthZ、Suggest 的共同身份事实来源。
