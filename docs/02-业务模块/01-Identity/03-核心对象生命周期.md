# Identity 核心对象生命周期

## User

```text
create
  -> active
  -> inactive / blocked
```

User 状态决定身份主体是否可用，但不表达认证会话和授权角色。

## Profile

```text
create
  -> update profile fields
  -> query by ID / name / IDCard
```

Profile 是业务档案事实，不负责登录凭证和权限。

## ProfileLink

```text
create active link
  -> query by user/profile
  -> revoke
```

撤销关系应保留历史事实，而不是把关系当作不存在过。
