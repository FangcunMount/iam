# AuthN 模块总览

## 模块定位

AuthN 负责认证，不负责授权判定或身份档案关系治理。

| 负责 | 不负责 |
| --- | --- |
| LoginIdentity | Role、Permission |
| Credential | ProfileLink |
| Challenge | Casbin Runtime |
| Principal | Suggest 索引 |
| Session、Token、JWKS | 外部身份源配置所有权 |

## 核心问题

```text
系统如何找到 User？
请求者如何证明自己控制某个 LoginIdentity？
认证成功后如何表达 Principal？
认证结果如何转换为 Session 和 Token？
```
