# AuthZ 核心对象生命周期

## Resource / Action / Scope

```text
define resource
  -> define supported actions
  -> validate scope
```

## Role / Permission

```text
create role
  -> grant permission
  -> revoke permission
```

## RoleBinding

```text
bind subject to role
  -> check effective permission
  -> unbind
```

## PolicyVersion

```text
authorization write
  -> increment PolicyVersion
  -> stage Outbox event
  -> runtime reload
```
