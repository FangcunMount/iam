# Suggest 模块总览

> 状态：待补证据 · 骨架初稿，待与代码/契约核对。

## 模块定位

Suggest 解决的是 Profile 候选项快速搜索体验：

```text
keyword
  -> normalize
  -> search index
  -> scope filter
  -> rank
  -> masked result
```

## 不负责

- 不负责 User / Profile 写模型。
- 不负责登录认证。
- 不负责通用授权策略管理。
- 不返回明文手机号。

## 核心规则

先做权限范围过滤，再排序截断，避免用户有可见结果却被全局高分无权限结果挤掉。
