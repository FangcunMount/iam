# Suggest 模型与应用端口

> 状态：已实现 · domain 分 `profile` / `visibility` / `search` 三包；application 分 `queryprofile` / `refreshindex`。

## 1. 30 秒结论

Suggest 是**策略型查询域**：domain 只表达读模型、可见范围与查询策略；TST/Hash 在 `infra/suggest/index/memory`。

查询用例链：

```text
Principal → AuthorizationFacts + Visibility → Scope
→ AdmissionPolicy → CandidateRecaller → SelectionPolicy → DisclosurePolicy
```

## 2. 对象速查

| 对象 | 所在层 | 作用 |
| --- | --- | --- |
| `profile.SuggestibleProfile` | domain | 索引读模型 |
| `visibility.Principal` / `Scope` | domain | 操作者与可见范围 |
| `search.AdmissionPolicy` / `Decision` | domain | 查询准入（无 Prometheus 字符串） |
| `search.SelectionPolicy` | domain | scope 过滤、去重、排序、limit |
| `queryprofile.CandidateRecaller` | application port | 索引召回（不含 scope 过滤） |
| `refreshindex.ProjectionChange` | application | Upsert/Delete 变更（非 domain mutation） |
| `refreshindex.ProjectionSource` / `IndexWriter` | application port | Full/Delta 数据源与物理写入 |
| `ProfileSuggestItem` | application DTO | transport 返回项 |

## 3. 配置归属（外部键不变）

| 配置键 | 归属 |
| --- | --- |
| `suggest.max_results` / `disable_mobile_mask` | `queryprofile.Config` |
| `suggest.internal_max_results` | `CandidateBudget` |
| `suggest.key_pad_len` / `trie_wildcard_key_cap` | `index/memory.Config` |
| `suggest.full_sql` / `delta_sql` | mysql Loader |
| `suggest.rate_limit.*` | ratelimit adapter |

外部配置键与 REST/指标 label **保持不变**。
