# Suggest 模块边界与代码索引

> 状态：已实现 · Suggest 是**策略型查询域**（非事务聚合域）；TST/Hash 属于 infra adapter。

## 1. 数据所有权

| 数据 | Owner | Suggest 中的形态 |
| --- | --- | --- |
| User/Profile/ProfileLink | Identity | Loader 输入，不可回写 |
| Principal/JWT context | AuthN | `visibility.Principal` 最小快照 |
| Role/route permission | AuthZ | `visibility.AuthorizationFacts` + Scope |
| SuggestibleProfile / TST / Hash | Suggest infra | 可丢弃的进程内派生状态 |
| 原始手机号 | Identity | 仅为获准精确搜索进入内存索引 |

## 2. 分层代码地图

### Domain

| 包 | 责任 |
| --- | --- |
| `domain/suggest/profile` | `SuggestibleProfile`、手机号脱敏策略 |
| `domain/suggest/visibility` | `Principal`、`Scope`、`ResolutionPolicy` |
| `domain/suggest/search` | `Keyword`、`AdmissionPolicy`、`SelectionPolicy`、`RankingPolicy` |

Domain **不含** TST、Prometheus、SQL、cron、物理索引 mutation。

### Application

| 包 | 责任 |
| --- | --- |
| `application/suggest/queryprofile` | 权限解析 → 准入 → 召回 → 选择 → 输出 |
| `application/suggest/refreshindex` | Full/Delta 游标、互斥、`ProjectionChange` |

Application 根包不再保留 transport façade；REST 直连 `queryprofile.Querier`。

### Infra

| 包 | 责任 |
| --- | --- |
| `infra/suggest/index/memory` | TST/Hash、快照、`CandidateRecaller` |
| `infra/suggest/authorization` | AuthZ facts reader |
| `infra/suggest/visibility` | visibility 缓存 |
| `infra/mysql/suggest` | Full/Delta SQL、visibility reader |
| `infra/suggest/metrics` | Prometheus 适配（映射 typed Decision） |
| `infra/suggest/ratelimit` | REST 限流 |

### Container / Transport

- `container/suggest`：配置拆分、`ModuleConfig`、cron 调度
- `transport/rest/suggest`：REST-only；依赖 `queryprofile.Querier` 与本地 rate-limit 端口

## 3. 依赖规则

```text
transport  → application → domain
container  → application + infra
infra      → application ports + domain
domain     → 标准库及 domain/suggest 子包
```

## 4. 未来 Elasticsearch

接入时仅新增 `infra/suggest/index/elasticsearch` adapter 与 container wiring；**不修改** domain 模型。
