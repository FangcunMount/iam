# 安全策略：手机号搜索、脱敏、限流

> 状态：待补证据 · 骨架初稿，待与代码/契约核对。

## 30 秒结论

手机号搜索是高风险能力，必须同时满足权限、脱敏、限流和审计/指标要求。

## 规则

- 只有 `AllowMobileSearch` 为真时，手机号形态关键词才允许命中手机号索引。
- 结果只返回 `mobile_mask`。
- 明文 mobile 不进入响应 DTO。
- 需要限流，防止枚举。
- 指标应能区分普通搜索和手机号搜索。

## 禁止

- 禁止手机号权限绕过 ProfileAccessScope。
- 禁止 Store 直接调用 AuthZ。
- 禁止把 ProfileLink 当成可见范围。
