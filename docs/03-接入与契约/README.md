# 03-接入与契约

## 本目录定位

`03-接入与契约/` 说明业务系统如何通过 REST、gRPC 和 Go SDK 接入 IAM。

机器契约优先于本文档：

- REST 以 `../../api/rest` 为准。
- gRPC 以 `../../api/grpc` 为准。
- Go SDK 以 `../../pkg/sdk` 为准。
