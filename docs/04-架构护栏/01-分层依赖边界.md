# 分层依赖边界

## 规则

```text
transport -> application -> domain
infra -> domain ports
container -> all layers for wiring
```

## 禁止

- domain 依赖 infra、transport、proto。
- application 依赖 transport 或具体 infra。
- transport 绕过 application 直接访问 repository、transaction、Casbin 或 container。
- SDK import IAM internal 包。
