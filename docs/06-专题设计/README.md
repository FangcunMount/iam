专题的目标是回答“为什么”，业务模块和基础设施文档回答“当前怎样做”。

一致性专题以宿主事务、Refresh交付未知、迟到撤销任务和Suggest旧资格等时序解释当前取舍，分别讨论事实提交、传播、读取证明与恢复。原子动作、TTL、ACK和健康不能互相代替；候选改造列出具体责任、成本和验收条件，入口算法继续回链主文。

威胁专题按攻击者权限与秘密副本划界，用扫码证明消费、合法Subject被错用、策略配置扩权、旧资格搜索和材料搬用解释当前阻断及剩余窗口。传输准入、有限委派、即时撤销、输出掩码与备份恢复各有责任；增强设计须说明owner、兼容成本和正反验收样本。

JWT/JOSE专题将协议格式、IAM Profile与消费方配置分开，用新kid未预热、旧公钥缓存、seed续龄、grace边界和DB/PEM恢复说明信任时效。正常轮换与安全退役需要不同接受样本；Profile收敛、预发布与不可续期信任截止均列出责任、兼容成本和验收条件。

Suggest专题解释身份事实、检索资料、物理索引、局部Scope与展示候选的责任。用号码/ID意图错配、预算外可见项、旧owner及晚提交说明取舍；直接SQL、同库投影和共享后端按需要改变的合同比较，可重建、新鲜度和业务许可分别验收。

授权快照专题用岗位范围错并、全局通配投影、坏目录、借入事务和恢复旧库解释领域事实与发布协议。Casbin、岗位继承、条件与消息交接分批取证；求值器替换、SQL、远程判定、增量分区按共同责任比较，候选成本与接受样本明确，运行状态不能由历史记录推导。
