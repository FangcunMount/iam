# 系统架构讲法

> 状态：待补证据 · 骨架初稿，待与代码/契约核对。

## 讲法主线

1. IAM 不只是用户中心，而是身份、认证、授权、接入契约的组合。
2. 运行时采用分层架构：process 管生命周期，container 管装配，transport 管协议，application 管用例，domain 管规则，infra 管外部资源。
3. 业务上分 3 个核心模块和 2 个辅助模块。
4. 工程上用 architecture tests、contract tests、SDK compile test 和 docs hygiene 防漂移。
