# 06-宣讲

## 本目录定位

`06-宣讲/` 面向技术分享、面试讲解和对外表达。它不替代事实层；所有讲法必须能回链到 [02-业务模块](../02-业务模块/README.md)、[03-接入与契约](../03-接入与契约/README.md) 或 [04-架构护栏](../04-架构护栏/README.md)。

## 推荐讲法

```text
一句话定位
  -> 模块协作图
  -> Identity / AuthN / AuthZ 三个核心模块
  -> IDP / Suggest 两个辅助模块
  -> REST / gRPC / SDK 接入
  -> 架构护栏和防漂移
```
