# IAM 文档归档区

本目录只保存已退出当前文档体系的历史材料。归档内容用于理解演进背景，不是当前代码、契约或运行行为的事实源。

## 当前状态

当前归档区保存已经完成使命、不能继续作为 active 操作入口的历史材料；本文件是归档区索引和使用约定。

## 使用规则

- 活跃文档不能依赖归档内容才能成立。
- 归档文件必须保留原始语境，并在文件开头标明归档原因和日期。
- 从归档材料恢复任何结论前，必须重新核对源码、OpenAPI、proto、配置、迁移和测试。
- 新增或移除归档文件时，必须在本页登记，不能留下只存在于索引中的“幽灵文件”。
- `make docs-hygiene` 检查本索引，但不要求历史正文持续符合当前代码路径和术语。
