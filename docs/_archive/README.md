# IAM 文档归档区

本目录保存历史分析、旧阅读指南和已冻结报告。这里的内容只用于理解演进背景，不是当前代码、契约或运行行为的权威事实源。

## 使用规则

- 活跃文档不能依赖本目录中的历史事实才能成立。
- 从本目录迁移任何结论到活跃文档前，必须重新核对源码、OpenAPI、proto、配置、迁移和测试。
- 默认 `make docs-hygiene` 不检查本目录。
